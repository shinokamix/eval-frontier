# Documentation

Start with the document that matches your task:

- Read [`METHODOLOGY.md`](METHODOLOGY.md) to understand the research question,
  design choices, and limits.
- Use [`SCORING.md`](SCORING.md) to implement method version `2.0` or look up a
  calculation rule.
- Use [`DATASETS.md`](DATASETS.md) to implement or inspect the data contract.
- Use [`VALIDATION.md`](VALIDATION.md) to build tests or decide whether a result
  can be published.
- Read [`../research/README.md`](../research/README.md) for the current pipeline,
  available evidence, and implementation plan.
- Follow [`../research/add-a-source.md`](../research/add-a-source.md) to add a
  source.

The method documents describe the target system. The research pipeline does
not implement the complete method yet. Check the implementation status before
interpreting a generated artifact as a cross-study result.
