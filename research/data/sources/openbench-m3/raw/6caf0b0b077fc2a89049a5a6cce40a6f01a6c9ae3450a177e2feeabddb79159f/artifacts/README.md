# M3 matrix run — 2026-07-02

Committed snapshot of the first full benchmark matrix (milestone M3). The raw,
append-only results log is `results.jsonl` (one JSON object per cell; schema
documented in the repo root `README.md` under "Results").

## What was run

- **Matrix:** 5 harnesses × 3 tasks × 5 trials = **75 real cells**, plus a
  **15-cell `null` negative control** (3 tasks × 5 trials) = **90 rows total**.
- **Harnesses:** `codex`, `pi`, `opencode`, `cursor`, `devin` (+ `null` control).
- **Tasks:** `fix-failing-test`, `build-a-cli`, `make-it-run`.
- **Model:** canonical `gpt-5.5-medium` for every cell (Track A — same model,
  harness varies).
- **Execution:** `--exec local` for all 90 cells. This is the official M3 ruling:
  the matrix runs all-local so we don't confound the harness comparison by mixing
  macOS-host and Linux-container execution. (Docker isolation exists and is
  proven, but only `codex`/`pi` are container-verified; see root `README.md`.)
- **Billing:** subscription OAuth only. The runner was launched with
  `OPENAI_API_KEY` unset in its environment (`env -u OPENAI_API_KEY python3
  bench/run.py ...`) so no harness could fall back to API-key billing —
  subscription routes use OAuth tokens, not the key. Verified zero adapter
  errors and zero API-key usage.

## Machine / provenance

- **Host:** macOS (single machine, single session, sequential run).
- **Date:** 2026-07-02.
- **Total compute:** sum of per-cell `wall_time_s` = 2886 s (~48 min).
- **Generated by:** `bench/run.py` (resumable; `run_id = harness:task:model:trialN`).

## Caveat: devin reasoning effort is unpinned

`devin` exposes no reasoning-effort selector, so canonical `gpt-5.5-medium`
collapses to plain `gpt-5.5` at whatever effort devin defaults to. Devin's rows
are therefore **not** an effort-for-effort comparison with the other harnesses —
treat them as approximate. All other harnesses pin `medium` effort explicitly.

## Reproduce the report

```
python3 bench/report.py --results-path data/m3-2026-07-02/results.jsonl
```
